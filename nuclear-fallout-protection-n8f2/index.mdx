export const DecontaminationSteps = () => {
  const [currentStep, setCurrentStep] = useState(0)
  const steps = [
    { title: "Remove Clothing", desc: "Removes ~90% of contamination", icon: "👔" },
    { title: "Bag It", desc: "Seal in plastic, set aside", icon: "🛍️" },
    { title: "Shower", desc: "Soap and water, head to toe", icon: "🚿" },
    { title: "Shampoo Only", desc: "NO conditioner (binds particles)", icon: "🧴" },
    { title: "Clean Clothes", desc: "Put on uncontaminated clothing", icon: "👕" }
  ]
  
  return (
    <div className="my-6 p-4 bg-gray-800/50 rounded-lg">
      <div className="flex justify-between mb-4">
        {steps.map((step, i) => (
          <button
            key={i}
            onClick={() => setCurrentStep(i)}
            className={`w-12 h-12 rounded-full flex items-center justify-center text-xl transition-all ${
              i === currentStep 
                ? 'bg-blue-600 scale-110' 
                : i < currentStep 
                  ? 'bg-green-600' 
                  : 'bg-gray-600'
            }`}
          >
            {step.icon}
          </button>
        ))}
      </div>
      <div className="text-center p-4 bg-gray-900/50 rounded animate-fade-in">
        <h4 className="text-xl font-bold text-blue-300">Step {currentStep + 1}: {steps[currentStep].title}</h4>
        <p className="text-gray-300 mt-2">{steps[currentStep].desc}</p>
      </div>
      <div className="flex justify-between mt-4">
        <button 
          onClick={() => setCurrentStep(Math.max(0, currentStep - 1))}
          className="px-4 py-2 bg-gray-600 rounded hover:bg-gray-500 disabled:opacity-50"
          disabled={currentStep === 0}
        >
          Previous
        </button>
        <button 
          onClick={() => setCurrentStep(Math.min(steps.length - 1, currentStep + 1))}
          className="px-4 py-2 bg-blue-600 rounded hover:bg-blue-500 disabled:opacity-50"
          disabled={currentStep === steps.length - 1}
        >
          Next
        </button>
      </div>
    </div>
  )
}

## ⏱️ THE CRITICAL FIRST 24 HOURS

<CountdownTimer hours={24} />

Fallout radiation intensity follows a predictable decay pattern:

| Time After Event | Radiation Level |
|-----------------|-----------------|
| 1 hour | 100% (most dangerous) |
| 7 hours | ~10% |
| 24 hours | ~1% |
| 2 weeks | ~0.1% |

**The "7-10 Rule":** For every 7-fold increase in time, radiation decreases by 10x.

## 🚪 When to Leave Shelter

<CriticalAlert>
Do NOT leave until official all-clear OR at least 24 hours have passed and you must leave for critical supplies.
</CriticalAlert>

### If You Must Leave Early

1. Minimize time outside (minutes, not hours)
2. Cover all skin
3. Wear mask/cover nose and mouth
4. Do NOT touch anything unnecessarily
5. Decontaminate immediately upon return
6. Do not bring outside items inside

---

## 📋 Quick Action Checklist

```
□ GET INSIDE (any building, NOW)
□ Go to interior room / basement
□ CLOSE all windows and doors
□ Turn OFF ventilation / HVAC
□ SEAL gaps (tape, wet towels)
□ DECONTAMINATE if exposed outside
□ MONITOR radio for updates
□ STAY INSIDE minimum 24 hours
□ RATION supplies if needed
```
