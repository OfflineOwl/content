# Home Hardening Basics

> **Your First Line of Defense** - Before you can shelter in place effectively, your home needs to be able to withstand threats. This guide covers practical ways to make your home more resilient.

## What is Home Hardening?

Home hardening means improving your home's ability to:
- Withstand natural disasters
- Resist forced entry
- Maintain habitability during emergencies
- Protect against environmental hazards

This isn't about building a bunker—it's about practical improvements that make a real difference.

### Reinforced Entry Procedure

The weakest point of most doors is the frame, not the lock.

**Strike Plate Upgrade (DIY):**
1. Remove existing strike plate
2. Install reinforced strike plate (3" version)
3. Use 3" screws that reach wall studs
4. Repeat for deadbolt strike

**Door Frame Reinforcement:**
- Install door frame reinforcement kit
- Covers vulnerable areas with metal
- Significantly increases kick-in resistance

## Utility Knowledge & Safety

### Know Your Shutoffs

Every adult in the household should know:

**Gas Shutoff**
- Location: Usually near gas meter
- Tool needed: Adjustable wrench or gas shutoff tool
- When to shut off: Smell gas, earthquake damage, evacuation
- **Important:** Don't turn back on yourself—call utility company

**Water Shutoff**
- Main shutoff location (usually near street)
- Interior shutoffs (under sinks, behind toilets)
- Water heater shutoff
- When to shut off: Pipe damage, contamination warning, freezing risk

**Electrical Main**
- Breaker box location
- Main breaker location
- How to kill all power
- When to shut off: Flooding, fire, electrical damage

### Label Everything

Create labels for:
- Main gas shutoff
- Main water shutoff
- Electrical panel (with circuit guide)
- Water heater controls
- HVAC system controls

## Weather-Specific Hardening

### Hurricane/High Wind

**Pre-Season:**
- Inspect roof for loose shingles
- Trim trees near house
- Clear gutters and drains
- Pre-cut plywood for windows
- Secure outdoor furniture/items
- Reinforce garage door

**Window Protection Options:**

| Method | Protection | Reusability | Cost |
|--------|------------|-------------|------|
| Plywood | Good | Multiple uses | $ |
| Storm panels | Better | Permanent | $$ |
| Impact windows | Best | Permanent | $$$ |
| Hurricane fabric | Good | Multiple uses | $$ |

### Tornado

**Safe Room Considerations:**
- Interior room, lowest floor
- No windows (or minimal)
- Under stairs can work
- Reinforce closet walls if chosen
- Pre-position supplies

**If No Basement:**
- Identify most interior space
- Consider pre-fab safe room ($$)
- Reinforce chosen room's walls
- Install door that opens inward

### Earthquake

**Secure Items That Can Fall:**
- Water heater (strapped to wall)
- Bookcases (anchored)
- Heavy mirrors/pictures (secured)
- TVs (strapped or wall-mounted)
- Heavy furniture (anchored)

**Structural:**
- Bolt house to foundation (retrofit)
- Brace cripple walls
- Secure chimney
- Flexible gas connections

### Wildfire

**Defensible Space Zones:**

| Zone | Distance | Action |
|------|----------|--------|
| Zone 0 | 0-5 ft | No combustibles, hardscape only |
| Zone 1 | 5-30 ft | Fire-resistant plants, no ladder fuels |
| Zone 2 | 30-100 ft | Reduced vegetation, spaced trees |

**Home Improvements:**
- Class A fire-rated roofing
- Ember-resistant vents
- Non-combustible siding
- Enclosed eaves
- Tempered/double-pane windows
- Metal gutters with guards

### Flood

**If in Flood Zone:**
- Elevate electrical systems
- Install check valves on pipes
- Elevate HVAC equipment
- Waterproof basement walls
- Grade landscape away from foundation
- Consider flood vents

**Preparation Items:**
- Sandbags (or quick-dam alternatives)
- Sump pump + backup
- Waterproof containers for valuables
- Knowledge of evacuation routes

## Security Hardening

### Deterrence Layer

- Motion-activated lighting (all entries)
- Visible security cameras (or realistic dummies)
- Security system signs
- Well-maintained appearance
- No hiding spots near entries
- Timer-controlled interior lights

### Detection Layer

- Door/window sensors
- Motion detectors
- Glass break sensors
- Driveway alert
- Dog (excellent detection!)

### Delay Layer

- Strong locks (see door section)
- Security film on windows
- Reinforced doors/frames
- Thorny bushes under windows
- Fence with locked gate

### Communication

- Security system with monitoring
- Two-way communication at door
- Phone charging station in safe room
- Backup communication method

## Safe Room Basics

A safe room isn't just for tornadoes—it's useful for:
- Severe weather
- Home invasion
- Shelter-in-place orders
- Medical emergencies (centralized supplies)

### Location Options

**Best:**
- Basement interior room
- First floor interior closet
- Bathroom (plumbing = stronger walls)

**Avoid:**
- Rooms with large windows
- Exterior walls
- Upper floors (for weather)
- Garage

### Safe Room Supplies

Keep in or near safe room:
- Water (1 gallon per person)
- First aid kit
- Flashlight and batteries
- Emergency radio
- Phone charger
- Whistle
- Basic tools
- Important documents
- Medications
- Blankets
- Snacks

### Communication from Safe Room

- Charged cell phone
- Written emergency numbers
- House phone (landline) if available
- Two-way radio if family is separated in house

## Emergency Power Options

### Backup Power Hierarchy

1. **Battery backups (UPS)** - For short outages, critical electronics
2. **Portable power stations** - For longer outages, flexible use
3. **Solar panels + battery** - For extended independence
4. **Generator** - For heavy loads, longest runtime

### Generator Safety

If using a generator:
- NEVER run indoors (CO poisoning risk)
- Place 20+ feet from windows/doors
- Use heavy-duty outdoor extension cords
- Never refuel while running
- Connect to appliances directly, NOT to house wiring
- Have carbon monoxide detectors active
