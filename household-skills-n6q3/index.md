# Household Skills Everyone Should Know

> **Basic Self-Reliance** - When help isn't available, basic household skills become essential. These fundamental abilities help you maintain safety and comfort during emergencies.

## Plumbing Basics

### Shutting Off Water

**Main shutoff:**
- Located near meter or where line enters home
- Turn clockwise to close
- Know location before emergency

**Toilet shutoff:**
- Valve behind toilet near floor
- Turn clockwise to close
- Stops running/overflowing toilet

### Unclogging Drains

**Plunger technique:**
1. Cover overflow hole (if present)
2. Add water to cover plunger
3. Create seal over drain
4. Push down, pull up forcefully
5. Repeat 10-15 times

### Stopping a Running Toilet

1. Remove tank lid
2. Lift float ball or adjust fill valve
3. Jiggle flapper to reseat
4. Adjust chain length if needed

## Electrical Basics

### Circuit Breaker

**When to use:**
- Power outage (check if tripped)
- Before electrical work
- To reset after overload

**Resetting breaker:**
1. Find tripped breaker (middle position)
2. Push fully OFF
3. Push firmly ON
4. If trips again, problem exists

### Power Outage Response

1. Check if just your home or neighborhood
2. Check main breaker
3. Unplug sensitive electronics
4. Avoid opening fridge/freezer
5. Report if widespread

## Fire Safety

### Using Fire Extinguisher

**PASS technique:**
- **P**ull the pin
- **A**im at base of fire
- **S**queeze the handle
- **S**weep side to side

### Putting Out Kitchen Fires

**Grease fire:**
- Cover with lid (smother)
- Use baking soda
- NEVER use water

**Oven fire:**
- Turn off oven
- Keep door closed
- Let it burn out

## Basic Repairs

### Patching a Hole in Wall

1. Clean edges of hole
2. Apply mesh patch or backing
3. Apply spackling compound
4. Let dry, sand smooth
5. Repeat if needed
6. Paint when complete

### Fixing a Leaky Faucet

Most common cause: Worn washer

1. Turn off water supply
2. Remove handle
3. Remove packing nut
4. Replace washer
5. Reassemble
6. Turn on water, test

## Sewing Basics

### Sewing a Button

1. Thread needle, knot end
2. Position button
3. Push needle up through hole
4. Push down through adjacent hole
5. Repeat 3-4 times
6. Wrap thread around base
7. Tie off on back

### Fixing a Tear

1. Thread needle
2. Start inside garment
3. Small stitches close to edge
4. Work both sides of tear
5. Tie off inside

## Tool Basics

### Essential Tools

- Hammer
- Screwdrivers (flat and Phillips)
- Pliers
- Adjustable wrench
- Tape measure
- Flashlight
- Duct tape
- Utility knife

### Safe Tool Use

- Right tool for the job
- Inspect before use
- Secure work piece
- Cut away from body
- Wear eye protection when needed
