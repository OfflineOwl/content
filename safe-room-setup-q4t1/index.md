# Safe Room Setup

> **A Room Within Your Home** - A safe room provides protection from various threats including severe weather, home invasion, and civil unrest. This guide covers setting up an effective safe room with minimal resources.

## Safe Room Purposes

A safe room can protect against:
- Tornadoes and severe storms
- Home invasion
- Civil unrest
- Chemical/biological events (shelter-in-place)
- Any situation requiring immediate secure shelter

## Choosing a Location

### Ideal Characteristics

**For weather protection:**
- Interior room
- Lowest floor (basement ideal)
- No windows (or minimal)
- Small footprint
- Under stairs works well

**For security threats:**
- Solid door (or reinforceable)
- Interior location
- Lockable from inside
- Communication access
- Bathroom nearby (if extended stay)

### Common Choices

| Room | Pros | Cons |
|------|------|------|
| Basement | Best weather protection | May not be lockable |
| Bathroom | Plumbing, small, often interior | Weak doors |
| Walk-in closet | Small, often interior | No facilities |
| Interior bedroom | Space, may have bathroom | May have windows |

## Reinforcing the Room

### Door Security

**Basic improvements:**
- Replace hollow door with solid core
- Install 3" screws in strike plate
- Add deadbolt
- Install door reinforcement kit
- Add door bar/security bar from inside

### Window Protection (if present)

- Security film
- Interior shutters
- Plywood cut to fit
- Bars (interior release)

### Walls

- Most interior walls are not bulletproof
- Brick, concrete, filled block provide protection
- For storm protection, get below ground level

## Essential Supplies

### Always Stocked

- [ ] Water (1 gallon per person minimum)
- [ ] First aid kit
- [ ] Flashlight + batteries
- [ ] Phone charger
- [ ] Emergency radio
- [ ] Whistle
- [ ] Important documents (copies)
- [ ] Blankets
- [ ] Medications

### For Weather Events

- [ ] Helmets or hard hats
- [ ] Thick blankets (debris protection)
- [ ] Sturdy shoes
- [ ] Mattress (to pull over you)

### For Security Events

- [ ] Phone (charged)
- [ ] Door reinforcement
- [ ] Communication with outside
- [ ] Self-defense items (legal, trained)

### For Shelter-in-Place

- [ ] Plastic sheeting
- [ ] Duct tape
- [ ] Wet towels
- [ ] N95 masks
- [ ] Extended supplies

## Communication

### Inside Safe Room

- Charged cell phone
- Backup phone charger
- Emergency radio
- Whistle (signaling)
- Paper and pen

### Outside Communication

- Let trusted contacts know your plan
- Check-in schedule
- Code words for distress

## Quick Entry Protocol

### When Threat Identified

1. **Alert** - Signal family ("SAFE ROOM NOW")
2. **Gather** - Everyone proceeds immediately
3. **Secure** - Last person locks/bars door
4. **Position** - All in designated spots
5. **Communicate** - Call 911 if appropriate
6. **Monitor** - Listen for developments
7. **Wait** - Stay until threat passes

### Practice Drills

- Practice getting to safe room quickly
- Time how long it takes
- Practice at night/in dark
- Include all family members
- Identify bottlenecks

## Advanced Considerations

### Ventilation

- Safe rooms need air exchange
- Consider air filtration for chemical threats
- Don't seal completely for extended periods
- Know when to ventilate

### Sanitation

For extended stay:
- Bucket with bags (emergency toilet)
- Cat litter or similar
- Hygiene supplies
- Trash bags

### Food

For extended stay:
- No-cook foods
- Water
- Comfort foods
- Plan for 24+ hours if possible
